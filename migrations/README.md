# DB マイグレーション

認証用のスキーマはまだ定義していません。現在の `/health` と `/ready` にテーブルは不要なので、初回起動時に `make migrate-up` を実行する必要はありません。

ユーザー・セッションなどの仕様が決まったら、連番の SQL ファイルを追加します。

```text
000001_create_users.up.sql    # テーブル等を作成する SQL
000001_create_users.down.sql  # 上記の変更を戻す SQL
```

SQL を追加してから `make migrate-up` で適用します。`make migrate-down` は一つ戻します。down の SQL によってデータが削除されるため、内容を確認して実行してください。SQL がない現在の状態では、これらのコマンドはマイグレーションファイルがない旨のエラーになります。

適用済みのマイグレーションは編集せず、新しい番号で変更を追加します。API はマイグレーションを自動実行しません。
